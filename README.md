# صيدلية د. سماح باسم — دليل التشغيل والحماية

## الفكرة
- **أنت** بترفع ملف الـ PDF بإيدك في مجلد `inbox` على GitHub (من الموبايل أو الكمبيوتر).
- GitHub بيحوّله لوحده لـ `public/data/products.csv` (الاسم، الكمية، السعر بس).
- الموقع بيتحدث تلقائيًا خلال 3–5 دقايق. **مفيش حاجة تتثبت على جهازك ولا حاجة تبعتها لحد.**

```
.github/workflows/   ← الشغّال التلقائي (متلمسوش)
inbox/               ← هنا بترفع الـ PDF (مش بيتنشر على الموقع)
tools/               ← أداة التحويل
public/              ← ده الوحيد اللي بيتنشر على الإنترنت
```

---

## التجهيز (مرة واحدة)

### 1) ريبو **Private** جديد
1. github.com ← **New repository** ← اختار **Private** ← سمّيه أي اسم ← Create
2. فُك ضغط الملف، وفي الريبو: **Add file ← Upload files** ← اسحب **محتويات** المجلد (مش المجلد نفسه) ← Commit
3. لو مجلد `.github` مظهرش بعد الرفع: **Add file ← Create new file** ← اكتب الاسم `.github/workflows/update-products.yml` والصق محتوى الملف ← Commit
4. الريبو القديم (لو كان Public) امسحه: Settings ← آخر الصفحة ← Delete this repository

> الأهم: الريبو لازم يفضل Private. الـ PDF فيه التكلفة ونسبة الربح. لو الريبو بقى Public، الشغّال بيرفض يشتغل ويطلعلك خطأ أحمر.

### 2) الاستضافة (Cloudflare Pages — مجاني، وبيدعم الريبو الخاص)
GitHub Pages المجاني مش بيشتغل مع الريبو الخاص، فالموقع بيتنشر من Cloudflare:
1. اعمل حساب على Cloudflare **وفعّل التحقق بخطوتين**
2. Workers & Pages ← Create ← **Pages** ← **Connect to Git** ← اختار GitHub وادّيه صلاحية **للريبو ده بس** (Only select repositories)
3. الإعدادات: Framework = **None** ، Build command = **سيبه فاضي** ، Build output directory = **`public`**
4. Save and Deploy. كل Commit بعد كده بيتنشر لوحده
(Netlify بنفس الإعدادات: Publish directory = `public`)

### 3) تأمين حساب GitHub
- Settings ← Password and authentication ← فعّل **Two-factor authentication** (تطبيق أو Passkey، مش SMS) واحفظ أكواد الاسترجاع في مكان بعيد عن الكمبيوتر
- Settings ← Collaborators: **متضيفش حد** (والريبو يبقى ليك لوحدك)
- متديش أي تطبيق صلاحية على كل الريبوهات بتاعتك، بس على ده

---

## كل يوم (دقيقة واحدة)
1. افتح الريبو ← مجلد **`inbox`** ← **Add file ← Upload files**
2. اسحب ملف الـ PDF (أي اسم) ← **Commit changes**
3. افتح تبويب **Actions**: لما يظهر ✅ أخضر (3–5 دقايق) الموقع اتحدث. الـ PDF بيتشال من `inbox` لوحده.

لو ظهر ❌ أحمر: افتحه واقرا الرسالة. غالبًا الملف مش تقرير الأصناف المعتاد أو ناقص صفحات. الموقع بيفضل بالبيانات القديمة (محدش بيتأثر). امسح الـ PDF من `inbox` وارفع الصح.

### حمايات التحويل
- لو العدد المقروء مش مطابق للمكتوب في آخر صفحة، أو الحسابات (الكمية × السعر) غلط، أو الملف أصغر من نص القديم ← **بيوقف ومبيغيّرش حاجة**
- مكتبة التحويل متثبّتة على إصدار محدد، والشغّال مصرّح له يكتب في الريبو ده بس

## مين يقدر يشوف إيه؟

| | الزائر | أنت بس |
|---|---|---|
| صفحات الموقع وقايمة الأصناف (الاسم، السعر، الكمية) | ✅ بيشوفها (هي المعروضة أصلًا) | |
| ملف PDF الأصلي | ❌ | ✅ |
| سعر التكلفة، نسبة الربح، اسم الشركة | ❌ مبتتنقلش للموقع نهائيًا | ✅ |
| الريبو، الكود، السجل، الإعدادات | ❌ | ✅ |
| تعديل الموقع | ❌ | ✅ |

⚠️ ملف `products.csv` بيتحمّل من أي زائر لأن الصفحة بتعرضه. ده يعني إن **الكميات** (مش بس الأسعار) ممكن حد ينسخها كلها مرة واحدة. لو الكميات بالتحديد حساسة، ينفع نعرض "متوفر" من غير رقم.

## حماية الموقع نفسه
- ملف `public/_headers` بيفعّل HTTPS الإجباري، ومنع تضمين الموقع في صفحات تانية (Clickjacking)، وسياسة Content-Security-Policy بتمنع تشغيل أي سكريبت غريب
- أي نص جاي من الـ CSV بيتعرض كنص عادي، مش كود
- Cloudflare بيحمي من هجمات الضغط (DDoS) تلقائيًا

## شكل الموقع وتصنيف الأصناف (النسخة الجديدة)
- الصفحة الأولى واجهة صيدلية (الباب بيتفتح)، وبعدها أربعة أقسام: **رجالي — نسائي — مستحضرات (مشتركة) — أدوية**. المستحضرات فيها فلتر: عناية وتجميل / مستلزمات طبية.
- **التصنيف تلقائي** من اسم الصنف (قواعد في أول `public/catalog.js`)، والأسماء بتتبسّط للاسم الشائع (بتتشال الأحجام والرموز، وبتتحول أشكال الدوا لعربي: قرص، كبسولة، شراب…).
- ترتيب الحياء: الأصناف العادية فوق، والحساسة في آخر الرف (فياجرا/واقيات في رجالي، فوط ومنتجات نسائية خاصة في نسائي، وأدوية حساسة في أدوية).
- **البحث بالعربي والإنجليزي:** "بنادول" بتطلّع Panadol، و"شامبو" بتطلّع Shampoo، وهكذا (مطابقة صوتية).
- **تصحيح يدوي:** أي صنف اتصنف غلط أو اسمه عايز تبسّطه، حطه في `public/data/overrides.csv`:
  `الاسم الأصلي, الاسم المختصر, القسم` — والقسم واحد من: رجالي / نسائي / مستحضرات / أدوية (سيب أي خانة فاضية لو مش عايز تغيّرها).
- الأصناف اللي كميتها صفر مش بتظهر، والكمية اللي أقل من واحد بتظهر "كمية محدودة".
- العربية بتتحفظ على جهاز الزائر، وزر الطلب بيفتح واتساب برسالة جاهزة بعد اختيار المنطقة.
